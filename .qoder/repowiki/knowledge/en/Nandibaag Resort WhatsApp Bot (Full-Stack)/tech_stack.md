Node.js 18+ / Express 4 + Socket.io 4 for the backend; Mongoose 8 + MongoDB for persistence; `whatsapp-web.js` with Puppeteer headless Chrome for WhatsApp Web automation; OpenAI SDK used as a unified client against multiple providers (Groq, Cerebras, OpenRouter, Ollama local) plus Google Generative AI SDK for Gemini and direct fetch for Cloudflare Workers AI; Winston for structured logging, PM2 `ecosystem.config.js` for production process management. Frontend uses React 18 + Vite 5 + TailwindCSS v4 + react-router-dom 6 + socket.io-client + axios + vite-plugin-pwa.
