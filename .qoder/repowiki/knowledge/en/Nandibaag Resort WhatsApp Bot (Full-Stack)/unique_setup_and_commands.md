Backend requires `cp .env.example .env` then `npm install && npm run dev` (nodemon on `src/server.js`, default port 7000). Production uses `pm2 start ecosystem.config.js` followed by `pm2 save` / `pm2 startup`. One-off scripts available via npm: `npm run setup` (env scaffolding), `npm run check-ports`, `npm run smoke-test`, `npm run seed-rooms`, `npm run test-ai`. Frontend runs separately with `cd frontend && npm install && npm run dev` (Vite on port 5173).
